Section 04 · Module 02
去重与聚类
识别相似新闻，合并同类项，将碎片化信息聚合为有意义的主题簇

三层去重策略

L1
精确去重URL哈希 + 标题哈希 → Redis BloomFilter
L2
近似去重SimHash / MinHash → 文本指纹相似度 > 0.9 判定重复
L3
语义去重Qwen3-Embedding 向量 → 余弦相似度 > 0.92 判定语义重复

聚类算法

方法说明
语义 Embedding使用 Qwen3-Embedding 将文章向量化
聚类算法HDBSCAN — 自动确定簇数量，优于 K-Means
簇合并策略同一簇内按时间排序，选取最早 + 最权威来源为代表
簇标签生成Qwen3.7 Max 自动生成簇的主题标签

条件边与循环逻辑

# 审核不通过 → 重新生成 (最多3次)
def review_router(state: PlatformState) -> str:
    if state["review_passed"]:
        return "compose"
    if retry_count >= 3:
        return "compose"   # 强制通过，附带审核意见
    return "research"      # 返回重新生成

# 采集失败 → 降级处理
def collection_router(state: PlatformState) -> str:
    if len(state["raw_articles"]) == 0:
        return "fallback_cache"   # 使用Redis缓存的昨日数据
    return "preprocess"

降级策略

请求 → 查Redis缓存
  ├── Hit → 直接返回
  └── Miss → 调用实际服务
              ├── 成功 → 写入缓存 + 返回
              └── 失败 → 返回降级数据 (过期缓存 / 默认值)

Section 09
关键技术难点与解决方案

长文本处理

挑战解决方案
单篇新闻超长RecursiveCharacterTextSplitter 智能分段
多文档上下文窗口超限Map-Reduce 摘要策略：先分篇摘要，再合并提炼
研报生成需要大量上下文RAG 分层检索 + Reranker 精选 Top-K 最相关片段

摘要质量保障

挑战解决方案
LLM 幻觉ReviewAgent 事实核查 + 引用溯源
内容空洞强制要求数据引用 + 结构化模板约束
观点偏颇多源交叉验证 + 平衡性检查 Prompt

工作流可靠性

挑战解决方案
Agent 执行失败LangGraph Checkpointing + 断点恢复
外部 API 不稳定Redis 缓存降级 + 指数退避重试
处理时间过长异步执行 + 进度回调 + 超时控制
